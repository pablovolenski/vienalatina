{{/* BreadcrumbList — where this page sits, for a search result and for an answer engine deciding what a page is about. Two levels: Inicio → this. Nothing is rendered visibly: the site is shallow enough that a visible trail would be clutter, while the machine-readable one still answers "what is this page part of".
