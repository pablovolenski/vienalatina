Built this way, a new page shows up when it is published, with its own translated title in each language. Two levels: a page with `parent: ` in its frontmatter hangs under the page with that basename. "base" $base "parent" (.Params.parent | default "") "w" (.Params.weight | default 50)) }} {{ end }} {{ $pages = sort $pages "w" }}
